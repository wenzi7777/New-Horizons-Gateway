# studio-v2.12.2

**卡片右上角的按鈕不再跑出卡片；Vref 掃描算不出 Rs 時會說明真正的原因；介面動畫全部改為緩動曲線。**

## 版面

- NH Studio 卡片標題旁的按鈕（例如 FindMe 卡片的「Run FindMe」）在說明文字較長時會超出卡片右緣。現在由標題讓位換行，按鈕保持完整寬度；視窗太窄時按鈕會移到標題下方。
- 設備頁頂部（名稱與在線狀態）、Profiles 標題列、App 安裝與 IO 設定對話框的標題列也一併修正。

## Vref 掃描（TIA-CTL v2.0.F）

- 只有不到兩個步驟算得出 Rs 時，不再誤導地提示「請先測量 Rfb」，改為提示掃描全程保持壓力，並建議下載 CSV 確認 `raw_mv` 是否隨 Vref 上升。
- 真的沒有 Rfb 時才顯示原本的提示。填寫的焊接 Rfb 只用在沒有量測值的列。

## 動畫

- NH Studio 與 NH Pocket 的轉場與動畫改為統一的緩動曲線（與 Desktop 共用 token）；載入圖示這類本來就該等速的動畫維持不變。

## 其他

- NH Pocket 2.12.2。搭配 Desktop v1.14.1；韌體不需更新。
