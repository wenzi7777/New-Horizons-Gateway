# studio-v2.2.0

**NH Studio 加入 TIA-CTL v2.0.F 的工具：Vref、校準開關、Rfb 量測、量程模式與 Vref 掃描。**

## 設備設定・硬體

- Vref 卡：目前值、上限、開機預設值與校準開關狀態；可設定 Vref、回到 330 mV、設定上限、開關校準開關。超過約 800 mV 重啟可能開機失敗，頁面會提醒。
- Rfb：「量測 Rfb」（可指定 Vref）列出每一行的 Rfb、ADC 偏移與狀態。
- 量程：Raw、Virtual Rfb、Auto，可設定基準 Rfb 與 GPIO45 漏電補償。量完 Rfb 後 Virtual 與 Auto 立即可選。
- Vref 掃描：在固定壓力下逐步改變 Vref，列出每步的 Rfb、Rs 中位數與碰到電源軌的格數，顯示 Rs 變動幅度並可下載 CSV。等待回覆的時間依掃描長度計算（最長 120 秒）。
- 由 ID 電阻辨識的電池會顯示容量與充電電流，隱藏手動設定表單，並列出電池 ID。

需要韌體 v1.21.0 以上（Rfb、量程與掃描需要 v1.22.0）。
