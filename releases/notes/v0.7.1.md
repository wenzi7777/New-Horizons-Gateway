# v0.7.1

**同一個 LAN 有兩台 Gateway 時，設備的 Gateway 不再在兩台之間來回切換。**

## FindMe 歸屬修正

- 以前 Gateway 只要收到設備的指令回覆，就把設備標成「已連線」。但不管指令是哪台 Gateway 送的，設備都會回覆；串流和 heartbeat 則只送給 FindMe 選中的那一台。
- 所以當 Desktop 經由另一台 Gateway 送出指令（例如設定頁定期拉 `status`），那一台也會宣稱接管設備 16 秒。Desktop 的下一次輪詢就改走它，回覆又讓它續上 16 秒，兩台 Gateway 就這樣輪流搶走設備，設定頁的 Gateway 欄位一直在兩台之間跳動。
- 現在指令回覆不再單獨代表「設備接在這台」：
  - `status` 回覆帶有設備自己的 FindMe 區塊，寫的是這台 Gateway 才算接在這裡；寫的是別台時，這台會立刻釋放設備。
  - 其他回覆不改變連線狀態，也不算存活訊號；設備接在哪一台只由 heartbeat 與串流決定。

## 相容性

- 搭配 Desktop v1.1.2（Desktop 也不再讓非服務中的 Gateway 靠指令回覆搶走設備）。只更新其中一邊，來回切換也會停止。
- 設備韌體不用改。
