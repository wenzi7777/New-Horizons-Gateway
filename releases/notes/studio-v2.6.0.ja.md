# studio-v2.6.0

**「近くのデバイス」を手動で探索できるようになりました。サインインはアカウントを記憶し、起動のたびに自動で行います。**

## デバイスの探索

- NH Studio のデバイスページと NH Pocket の「近くのデバイス」に「探索」ボタンを追加しました（Desktop の管理画面の「探索」と同じです）。押すとネットワーク上の各デバイスがこのコンピューター/スマートフォンに直接応答するため、別の中継（NH Studio headless など）が使用中のデバイスも表示され、そのまま「引き継ぐ」ことができます。Wi-Fi のアクセスポイントがデバイスのブロードキャストを転送しないネットワーク向けです。サインインは不要です。
- NH Studio headless のローカル WebUI には以前から「探索」ボタンがあります。

## サインイン

- NH Studio / NH Pocket はサインインしたアカウントを記憶し（Studio はシステムのキーチェーンで、Pocket は Android のセキュアストレージで暗号化）、起動時・サーバー切り替え時・トークンが無効になったときに自動でサインインし直します。記憶したパスワードが使えなくなったとき（パスワード変更、アカウント無効化）だけサインインを求めます。
- app token を貼り付ける方法は削除しました。New Horizons Desktop v1.10.0（Relays ページのトークン管理を廃止）と組み合わせて使います。
- 旧バージョンから更新した場合は、設定で一度サインインし直してください。以降は自動でサインインします。

## 修正

- サーバーがトークンを拒否したことを、ラベルとプロファイルの同期が検知できていなかった問題を修正しました。
