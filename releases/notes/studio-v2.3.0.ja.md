# studio-v2.3.0

**NH Pocket に録画の分析を追加。NH Studio は CSV を開くときにイベントとメタも読み込みます。**

## NH Pocket

- 録画ごとに**分析**画面を追加しました（録画を開いて「分析」）。概要、合計・最大・接触面積・指定センサーの波形（カーソルをドラッグでき、0.5×・1×・2×・4× で再生も可能）、カーソル位置のフレーム（または表示範囲の平均・最大）のヒートマップ、欠落フレーム・途切れ・再起動を一覧してタップで移動できるサンプリング品質、センサーごとの統計、録画のイベントを表示します。
- CSV は分割して読み込むため、長い録画でも画面が固まりません。分析できるのはスマートフォンで記録した録画です。

## NH Studio

- ツール > データ分析: ディスク上の CSV（Desktop のエクスポートなど）を開くと、隣にある `.events.csv` と `.meta.json` も読み込み、イベント、デバイス情報、ヒートマップの列数が表示されます。
- 録画ページに**分析**ボタンを追加しました。選択した録画を分析ツールで開きます。
