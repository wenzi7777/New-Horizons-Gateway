# studio-v2.1.0

**初回ガイド、Desktop のデバイス設定とビジュアライゼーション、すべて自前のコントロール、中継性能テスト。ラベルとプロファイルはサーバーが基準に。headless は Hub と同じ扱いに。**

## 初回起動

- NH Studio と NH Pocket は初回起動時にガイドを表示します：サーバーの選択 → Desktop アカウントでサインイン（スキップ可）→ 録画を自動アップロードするか → デバイスの受け入れ方。
- 受け入れ方の既定は「追加したデバイスだけ」。「求めてきたすべてのデバイス」は旧 NH Gateway と同じ動作です。設定からガイドを再表示できます。

## NH Studio

- デバイス設定を Desktop と同じにしました：概要、ハードウェア、ストリーミング、アップデート、診断の 5 つの区分、同じカードとコマンド。
- ライブビューは Desktop のビジュアライゼーション：3D サーフェス / 2D ヒートマップ、プロファイル選択、ミラー、統計と圧力中心。
- ドロップダウン、入力欄、チェックボックス、スイッチをすべて自前のコンポーネントにし、ネイティブのものは使いません。アイコンボタンは大きくしました。
- Windows / Linux ではシステムのタイトルバーとメニューバーをなくし、自前の最小化 / 最大化 / 閉じるボタンに。macOS は変わりません。
- macOS は ad-hoc 署名に：Apple Silicon で「壊れている」と表示されなくなりました。初回は「システム設定 → プライバシーとセキュリティ」で「このまま開く」を押してください。
- 上部バーに「Desktop を開く」ボタンを追加。

## NH Pocket

- スイッチ、ドロップダウン（下からのシート）、入力欄を自前のコンポーネントに。2D ヒートマップは Desktop の配置・P 番号・凡例で描き直し、セルをタップすると値を表示します。
- 設定に「Desktop を開く」を追加。

## ラベルとプロファイルはサーバーが基準

- ニックネーム、グループ、プロファイルは双方向同期をやめ、サーバー上のデータを直接編集します。手元には読み取り専用のコピーだけを持ちます。
- オフラインまたは未サインインのときは編集できず、「サーバーへの接続が必要です」と表示します。

## 中継性能テスト

- Studio の「ツール → 中継性能」、Pocket の「設定 → 中継性能」、headless の `nh-studio --bench`：この機器が処理できるフレーム数、サーバーまでの往復時間とアップロード速度を測り、中継できるデバイス数とボトルネックを示します。

## NH Studio headless

- Hub と同じ扱いに：接続種別 `relay`、サインイン不要、中継のみで録画しません。`--login` と WebUI のサインインカードを削除しました。

## その他

- 公開ファイルは VirusTotal でスキャンし、ダウンロードページに結果を表示します。
- New Horizons Desktop v1.5.0 以降が必要です。ファームウェア v1.20.0（デバイスがホストの間を行き来しなくなる）との組み合わせをおすすめします。
