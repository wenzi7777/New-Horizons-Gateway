# v1.0.0

**Gateway 可以在 Desktop 上管理了（跟 Hub 一樣），需要更新時也會在閒置時自動更新。**

## Desktop 遠端管理

- Relays 頁面的 Gateway 卡片多了「管理」，可以：
  - 看總覽（版本、通道、連線目標、服務中的裝置）
  - 改連線設定：Gateway ID、目標（production / local / manual）、manual URL
  - 檢查更新、立即更新、切換 stable / beta 通道
  - 管理 LAN 裝置：探索、允許、拒絕、接管
  - 重新啟動、恢復預設設定
- 遠端不能「停用」Gateway：停用後 Desktop 就連不到它了。
- 恢復預設會清掉 Gateway ID 並停用，Gateway 會離線，需要回到 Gateway 本機 WebUI（`http://127.0.0.1:5052`）重新設定。

## 閒置自動更新

- 以前 Desktop 告知有新版時，Gateway 只會鎖住本機 WebUI，一定要有人去按「更新」。
- 現在比照 Hub：啟動 60 秒後，只要 60 秒內沒有服務任何裝置，就自動下載並套用更新。
- 嘗試失敗後 30 分鐘內不再自動重試。

## 修正

- 本機 WebUI 的「重新啟動」在沒有待切換的版本時，以前其實會把 Gateway 關掉；現在會真的重新啟動。

## 相容性

- 搭配 Desktop v1.2.0 才有「管理」視窗；舊版 Desktop 照常運作，只是不能遠端管理。
- 從 v0.7.x 升到 v1.0.0 需要在 Gateway 本機 WebUI 手動更新一次（舊版不會自動更新）；之後就能從 Desktop 遠端更新。
- 裝置韌體、Hub 都不用改。
