# studio-v2.15.0

**NH Studio 與 NH Pocket 新增磁力計開關（預設關閉）與硬鐵/軟鐵校正精靈，校正到期或疑似失準時會提醒。**

## 磁力計開關（NH Studio / NH Pocket）

- 設備設定新增磁力計區塊：用「開啟 / 關閉」選單加「套用」切換，並可設定校正提醒間隔（7 / 14 / 30 / 90 天或不提醒）。NH Studio 放在 IMU 旁，NH Pocket 放在設備畫面。
- 選開啟並套用後，會直接進入校正精靈。沒有套用校正就離開時，磁力計會關回去。
- 顯示晶片 ODR、平均次數與實測速率。GCU 上 IMU 關閉時，會提示磁力計被 IMU 擋住。

## 校正精靈

- **準備**：提醒先裝好外殼與電池，並遠離筆電、鋼桌和馬達。
- **轉動**：動畫示範「畫 8 字、翻到各個面」。球面分成 26 格，收到資料的方向會亮起，並標出下一個該轉向的方向。下方顯示覆蓋率環與點數。
- **結果**：顯示三個投影的前後對比、場強、殘差（超過 5% 會建議重做）與模式。覆蓋率 ≥ 70% 且點數 ≥ 300 時做完整橢球擬合，覆蓋不足時只做硬鐵。新的擬合會疊在目前的校正上，取消時保留原本的校正。
- 維護區塊可以隨時重做或清除校正。

## 提醒

- 磁力計開著時，設備清單會在校正快到期（3 天內）、已到期、疑似失準或尚未校正時顯示徽章，設備設定會顯示提示條和「立即校正」按鈕。只做提醒，不會擋錄製或串流。

## 其他

- NH Studio 的 IMU 資訊顯示晶片 ODR；終端機新增 `set-mag` / `set-mag-calibration` 指令建構器。
- NH Pocket 2.15.0；NH Studio headless 可轉送新指令。需要韌體 v2.4.0，搭配 Desktop v1.18.0。
