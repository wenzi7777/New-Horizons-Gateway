# v0.5.5

## Fix: direct runtime start crashed without `NEWHORIZONS_GATEWAY_EXPECTED_VERSION`

`main.py` used `__version__` as the default for the expected-version check but
never imported it. The bootloader path always sets
`NEWHORIZONS_GATEWAY_EXPECTED_VERSION`, so production was fine; starting the
runtime module directly raised `NameError: name '__version__' is not defined`.

Import `from . import __version__` so both bootloader and direct runtime paths
work.
