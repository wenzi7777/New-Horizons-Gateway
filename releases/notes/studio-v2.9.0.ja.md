# studio-v2.9.0

**NH Studio と NH Pocket に IO ビジュアライザーを追加。基準電圧を「手動 + 2 つのスイッチ」に変更し、録画ファイルに v2.0.F の読み取り方式を記録します。**

## IO ビジュアライザー

- NH Studio：デバイス設定のピン配置カードに「IO ビジュアライザーを開く」を追加しました。左に基板図（v1.0.F、v1.5.F、v2.0.F、GCU v2.1 / v2.2.C / v2.3.D）、右でアナログピンとセレクトピンをマトリクスの順にタップし、そのまま適用するかターミナルのコマンドとしてコピーできます。Desktop と同じです。
- NH Pocket：デバイス画面に「IO ビジュアライザー」を追加しました。上に基板図、下でピンを順にタップし、確認後に適用します（`set_matrix_layout`）。
- 基板ごとのピンデータを Studio と Pocket 共通の `@nhgw/host` に移しました。

## 基準電圧 (TIA-CTL v2.0.F)

- Studio と Pocket の Raw / 仮想 Rfb / 自動 を 2 つのスイッチ（「基準スケールに換算」とその上の「スマート Vref 調整」）にしました。両方オフが手動で、v1.5.F 以前の基板と同じ読み方です。スマート調整は換算がオンのときだけ使えます。Studio の基準 Rfb と漏れ補正は「詳細設定」に移しました。
- 外部 LED モードをスイッチにしました。

## 録画

- `.meta.json` に `range`（モード、Vref、基準 Rfb、漏れ補正、行ごとの Rfb とオフセット。v2.0.F のみ）を追加し、録画中の変更は `changes` に記録します。New Horizons Desktop v1.13.0 とバイト単位で同じです。

## その他

- FindMe カードが 2 つの値の間で切り替わらなくなりました。relay のスナップショットが、デバイス自身が報告する relay のアドレスと起動後ミリ秒を上書きしなくなり、「最終成功」は起動後の秒数で表示します。
- アプリ：実行中カードに外部 LED ストリップを表示し、複数のアプリが点灯させうるときは「共有」と表示します。
- New Horizons OS v2.1.0、New Horizons Desktop v1.13.0 と組み合わせて使います。
