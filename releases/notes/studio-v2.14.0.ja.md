# studio-v2.14.0

**ライブ画面に「転置」を追加。NH Pocket のライブ画面を Desktop のビジュアライゼーションカードと同等に（3D を含む）。Gyro / Acc をグラフィック表示にし、磁気センサーも表示します。**

## 転置（NH Studio / NH Pocket）

- 行ミラー / 列ミラーの隣に「転置」：行と列を入れ替えます（6 × 8 が 8 × 6 に）。ヒートマップ、3D サーフェス、COP、サイズ表示も追従します。転置してからミラーするので、3 つの組み合わせで 8 通りの向きすべてになります。
- 表示のみ：記録は変わらず、P 番号はセンサーに付いて動き、A.. / D.. ピン表示は軸と一緒に入れ替わります。センサー配置プロファイル選択中は使えません。
- NH Studio：プロファイル選択時のミラーはセンサーの位置を動かすようになりました（値は元のセンサーのまま）。Desktop と同じです。以前は別のセンサーの値が表示されることがありました。

## NH Pocket のライブ画面

- 3D サーフェス（1 本指で回転、2 本指でズーム。変化があるときだけ描画し、画面外では停止）と 2D ヒートマップの切り替え。3D を描けない端末では 2D に切り替えます。
- センサー配置プロファイル（サーバーから同期。設定でサインイン）：プロファイルの画像上に点で表示し、点サイズを変更できます。
- 行ミラー / 列ミラー / 転置とマトリクスサイズ。統計：サンプル数、Device FPS、Render FPS、Max P、平均、COP。
- デバイスごとの表示設定を記憶します。

## IMU と磁気センサー（NH Studio / NH Pocket）

- Gyro / Acc を 3 つのパネルに置き換え：それぞれメーター + 直近 10 秒の X / Y / Z トレンド線 + 同色の数値。加速度センサー（水準器、|a|、ロール / ピッチ）、ジャイロ（中央基準バー、30–2000 °/s 自動スケール）、磁気センサー（新規。ボード +X の方位ダイヤル、加速度で傾き補正、µT と |B|。方位は生値）。磁気センサーのないデバイスはその旨を表示します。
