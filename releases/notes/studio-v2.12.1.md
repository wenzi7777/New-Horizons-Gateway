# studio-v2.12.1

**補上 v2.12.0 漏換的 NH Studio 圖示：側邊欄、啟動畫面、Windows／Linux 系統匣，以及 Windows 安裝精靈現在都是新圖示。**

- v2.12.0 已更換應用程式圖示與「關於」頁，但側邊欄左上角、啟動畫面和系統匣仍是舊圖示。
- Windows 安裝／解除安裝精靈的歡迎頁側圖與各頁標題圖原本是 NSIS 預設圖片，現在換成新圖示的版本；安裝程式、解除安裝程式與 macOS 磁碟映像也明確使用新圖示。
- 產生圖示的腳本現在也會直接寫入這些內建副本與安裝精靈圖片，之後不會再漏。

## 其他

- NH Pocket 不變（2.12.0，圖示已是新的）。韌體與 Desktop 不需更新。
- macOS 若 Dock 或 Finder 仍顯示舊圖示，是系統圖示快取，重新啟動 Dock（或登出再登入）即可。
