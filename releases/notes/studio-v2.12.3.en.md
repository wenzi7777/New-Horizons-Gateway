# studio-v2.12.3

**NH Pocket's relay performance results are no longer cut off.**

## NH Pocket

- In Settings → Relay performance, results such as "3,560 fps · 35 devices" or the server link wrapped to a second line in longer languages like Japanese, and that line was cut off. The rows now grow with their content, so every value shows in full.
- Shorter values: "frames/s" is now "fps", and "sign in to measure the upload" moved from the server link row to the note below.
- The server URL and sync queue in Settings wrap the same way.

## Other

- NH Pocket 2.12.3; no functional changes to NH Studio or headless. Goes with Desktop v1.15.0 (tidier Relays page, offline relays nobody signed in with removed after 1 day); no firmware update needed.
