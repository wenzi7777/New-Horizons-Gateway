# studio-v2.1.3

**サーバーがキーを拒否したときのサインイン画面と、Studio / Pocket 間のデバイス引き継ぎの高速化。**

- サーバーがこのアプリのキーを受け付けなくなったとき（無効化またはサーバーのリセット）、NH Studio は毎秒の無言の再接続ではなく、再サインインを求めます。サーバーが接続を切り続ける場合、再接続の間隔は最大 10 秒まで延びます。
- 別の NH Studio / NH Pocket に引き継がれたデバイスは、相手の ID に関わらずマイデバイスから外れます。
- NH Studio は FindMe プローブを各ネットワークのブロードキャストアドレスにも送ります。macOS では汎用ブロードキャストが数分間失敗することがあり、引き継ぎをより早く検出できます。
