# studio-v2.15.0

**NH Studio と NH Pocket に地磁気センサーのオン/オフ（既定はオフ）とハードアイアン/ソフトアイアン校正ウィザードを追加し、校正の期限切れやずれの疑いをお知らせします。**

## 地磁気センサーのオン/オフ（NH Studio / NH Pocket）

- デバイス設定に地磁気センサーの欄を追加しました。「オン / オフ」メニューと「適用」で切り替え、校正リマインダーの間隔（7 / 14 / 30 / 90 日、または通知なし）を設定できます。NH Studio では IMU の横、NH Pocket ではデバイス画面にあります。
- オンを選んで適用すると、そのまま校正ウィザードが開きます。校正を適用せずに閉じると、地磁気センサーはオフに戻ります。
- チップの ODR、平均回数、実測レートを表示します。GCU で IMU がオフのときは、地磁気センサーが IMU のために使えないことを表示します。

## 校正ウィザード

- **準備**：ケースとバッテリーを取り付け、ノートPC、スチール机、モーターから離すよう案内します。
- **回転**：「8 の字を描く、各面に向ける」動作をアニメーションで示します。球面を 26 区画に分け、データが集まった方向が点灯し、次に向けるべき方向を示します。下にカバー率のリングと点数を表示します。
- **結果**：3 つの投影で校正前後を比較し、磁場強度、残差（5% を超えるとやり直しを勧めます）、モードを表示します。カバー率 70% 以上かつ 300 点以上なら楕円体全体をフィットし、足りなければハードアイアンのみを校正します。新しいフィットは現在の校正に重ねて適用し、キャンセルすると元の校正が残ります。
- メンテナンス欄から、いつでもやり直しや消去ができます。

## お知らせ

- 地磁気センサーがオンのとき、デバイス一覧に、期限が近い（3 日以内）、期限切れ、ずれの疑い、未校正のバッジを表示し、デバイス設定にお知らせと「今すぐ校正」ボタンを表示します。お知らせだけで、録画やストリーミングは止めません。

## その他

- NH Studio の IMU 情報にチップの ODR を表示します。ターミナルに `set-mag` / `set-mag-calibration` のコマンドビルダーを追加しました。
- NH Pocket 2.15.0。NH Studio headless は新しいコマンドを中継します。ファームウェア v2.4.0 が必要で、Desktop v1.18.0 と組み合わせて使います。
