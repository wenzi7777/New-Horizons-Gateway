# studio-v2.0.1

**修正：NH Studio と NH Pocket が同じデバイスを管理していると、デバイスが両者の間を行ったり来たりしていました。**

## 原因

- デバイスは 3 秒ごとに FindMe を送り、その回で最初に届いた offer を受け入れます。2 台が同じデバイスを管理していると、返事が先に届いたほうに切り替わるため、数秒ごとに接続先が変わっていました。

## 修正

- デバイスが今ストリームを送っているホストはすぐに返事をし、ほかのホストは 250 ms 遅れて返事をします。デバイスは元のホストにとどまります。
- 元のホストが電源オフや切断のときは、ほかのホストの返事が有効になり、自動で切り替わります。
- 別のホストで「追加」を押すとすぐに切り替わります（claim つきの返事は常に即時）。
- NH Studio、NH Studio headless、NH Pocket のすべてを修正しました。Pocket v2.0.0 はアプリ内でアップデートできます（設定 → ソフトウェア・アップデート）。

## 注意

- 旧 Python Gateway は受け取るとすぐに返事をするため、引き続き Studio / Pocket とデバイスを取り合います。NH Studio headless に切り替えてください。
