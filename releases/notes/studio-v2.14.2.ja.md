# studio-v2.14.2

**NH Pocket で 3D に切り替えるとアプリが終了する問題を修正。デバイス画面の表示がなめらかになり、3D は斜めから表示します。**

## NH Pocket

- 3D でのクラッシュ：リリースビルドのコード縮小で 3D 表示に必要な部分が削除され、3D に切り替えるとアプリが終了していました。3D が正しく表示されるようになりました（Pixel 4a で確認）。
- 保護：それでも 3D を表示できない場合は 2D に切り替えてお知らせを表示し、ほかの画面でエラーが起きた場合はアプリを終了せずに「再試行」を表示します。
- デバイス画面を開くとき：ボード図とデータ経路は開くアニメーションが終わってから描画するため、カクつかなくなりました。ライブ画面のヒートマップ / 3D と IMU パネル、IO Visualizer のピン図も同様です。fps の数値やタイマーが変わるたびにデバイス画面全体を描き直すこともなくなりました。
- 3D は真上からではなく、Desktop と同じく斜め上からの視点で始まります。

## その他

- NH Pocket 2.14.2。NH Studio と NH Studio headless はバージョン番号のみ変更。Desktop とファームウェアの更新は不要です。
