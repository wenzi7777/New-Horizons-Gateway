# studio-v2.2.1

**NH Studio と NH Pocket が、起動中に新しいバージョンを知らせるようになりました。**

- これまで Studio と Pocket は起動時にだけ更新を確認し、結果は設定画面にしか出ませんでした。開きっぱなしの Studio や、中継サービスでバックグラウンドに残る Pocket は、新しいリリースに気づけませんでした。
- 数時間おきに再確認し（Pocket はフォアグラウンドに戻ったときも）、新しいバージョンがあればリリースノート、「後で」、インストールのボタン付きのダイアログを表示します。「後で」はそのバージョンにだけ有効です。
- Studio の「起動時に更新を確認」のスイッチは、この定期確認も制御します。

2.2.1 より前のバージョンにはこの機能がありません。一度、設定画面から手動で更新してください。
