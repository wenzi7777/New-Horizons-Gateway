# studio-v2.10.0

**TIA-CTL v2.0.F の読み取りが ADC mV・電導 µS・電導＋スマート Vref の 3 択になり、電導モードでも校正できます。記録にはフレームごとの単位・Vref・飽和行が加わりました。**

## 読み取りモード（TIA-CTL v2.0.F）

- NH Studio：基準電圧カードの読み取りは 1 つの選択肢（ADC mV、電導、電導＋スマート Vref）になり、「適用」で送信します。「換算」と基準 Rfb は削除し、Rfb 表は行ごとの状態を表示します。
- NH Pocket：読み取りは 3 つのセグメント（生値、µS、µS スマート）で、「適用」で送信します。
- 電導には先に Rfb の測定が必要です。未測定の行は 0 を出力します。

## 記録

- デバイスがフレームごとのレンジ情報を送ると、CSV に `range_unit`、`vref_mv`、`saturated_rows` の 3 列が加わります。Desktop の記録とバイト単位で一致します。
- `.meta.json` の range は読み取りモード、出力単位、スマート Vref、Vref、Rfb、offset、行ごとの状態を記録し、calibration にはプロファイルの単位（`unit`）が加わりました。

## 校正（NH Studio）

- 校正ページにプロファイルの単位を表示します。現在の出力単位と違うときは「保持するが適用しない」ことを示し、電導モードでは Vref が変わっても校正が有効なことを示します。
- Rfb のないセンサーはフィット失敗に数えず、進捗は Rfb のあるセンサーだけで数えます。
- 新しいエラーメッセージ：校正中に出力単位が変わった、プロファイルの単位が違う。
