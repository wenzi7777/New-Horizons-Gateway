# v1.2.0

**NH Gateway 的最後一版：之後由 NH Studio 取代。**

- WebUI 最上方顯示「NH Gateway 已由 NH Studio 取代」，並連到下載頁。
- 這一版照常運作，不必立刻更換；之後的新功能只會加在 NH Studio。
- NH Studio 以同樣方式轉送裝置（UDP、FindMe），而且會沿用這裡的設定：放進同一個資料夾或在同一台電腦啟動時，自動接手設定，Gateway ID 不變，伺服器上仍是同一台。
- 沒有螢幕的電腦請用 NH Studio headless 版（`nh-studio`），改用 Desktop 帳號登入（`nh-studio --login`）。
