# studio-v2.13.0

**NH Studio 與 NH Pocket 改用「插圖」介面：設備是一張板子圖，即時數值用引線標在實際的零件旁；設備連上後設定立刻出現，不必再按重新整理。**

## 插圖介面（v2.0.F / v1.5.F / v1.0.F）

- 設定 → 一般新增「介面」（插圖／經典），預設插圖，可切回經典。GCU LTS 板沒有插圖，維持原本的卡片。
- 設備總覽：板子的向量圖（依 PCB 檔的實際位置，隨亮色／深色主題變色），兩側是可點的數值——電池、讀數模式、掃描 FPS 與矩陣、連線、韌體、燈號；點一下跳到對應的設定。掃描與腳位合成一個「矩陣」標籤，引線分岔到兩個 FPC。
- 電源與連線路徑：USB-C／電池 → 充電 → 系統、設備 → 中繼 → 伺服器，正在使用的路徑以實線標示；文字太長時中間省略，不再被切掉。
- IO Visualizer：兩個 FPC 的放大圖，每支腳一個方塊，已啟用的亮起。
- 讀數模式、掃描預設、串流緩衝、更新通道、主題等改用大型選項按鈕（選中打勾），一樣按「套用」才送出。
- 充電中的電池圖示：閃電畫在電池裡面並加挖空外框，更明顯。

## NH Studio

- 設備連上（或重新連上）後自動向設備要一次狀態，設定面板不再是空的；沒回應時每 15 秒重試，最多 5 次。NH Pocket 同樣適用。
- 設備設定照 Desktop 重新分組：連線、硬體、串流、時鐘、更新、維護、App、診斷、檔案、實驗性。「概要」改名「連線」；重新啟動移到「維護」；濾波與 Raw ADC 移到「實驗性」；日誌移到「檔案」。
- 「診斷」新增設備健康卡（開機時數、開機與當機次數、重置原因、OTA 回滾、晶片溫度、最低可用記憶體、Wi‑Fi 斷線次數），與 Desktop 相同。
- 工具 → 設備檔案改成 Desktop 的 Finder 式視窗：左側範圍欄（含檔案數）、檔案清單、可收起的預覽面板、底部儲存空間列。
- 修正「Generate code」與 IO 視窗的「複製」一律失敗：現在 Studio 自己的頁面可以寫入剪貼簿（其他權限仍全部拒絕）。

## 其他

- 修正 v1.5.F / v2.0.F 數位 FPC 的腳位標示：接點 18 = GND、17 = SCL（GPIO 42）、16 = SDA（GPIO 40）、15 = NC。
- IO Visualizer 的板子圖縮小（Studio 460 px、Pocket 280 pt）；顯示 v2.0.F 背面 Rfb0–13 的位置與哪些已焊上。
- NH Pocket 2.13.0；NH Studio headless 只改版號。搭配 Desktop v1.16.0；韌體不需更新。
