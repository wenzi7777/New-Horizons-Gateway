# studio-v2.1.1

**修正裝置在 Studio / Pocket 之間遷移的問題：一台裝置只有一個主人；NH Pocket 新增「結束」。**

## 裝置遷移

- 裝置被另一個 NH Studio 或 NH Pocket 加入後，原本管理它的那一台會自動把它從「我的裝置」移除並停止錄製，不再兩邊都留著。連到 Hub 或伺服器的 FindMe 回應器不算換主人。
- 管理中的裝置一旦安靜下來，會發出探測，確認它是不是已經被別人接走。
- 畫面與中繼引擎改用同一份設定，避免 Pocket 已經在中繼裝置、卻仍把它列在「附近的裝置」的狀況。

## NH Pocket

- 設定頁新增「結束 NH Pocket」：停止中繼服務並完全關閉 App。從後台滑掉並不會結束中繼，狀態會留在背景。
