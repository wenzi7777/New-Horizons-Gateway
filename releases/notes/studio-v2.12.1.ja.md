# studio-v2.12.1

**v2.12.0 で変わっていなかった NH Studio のアイコンを更新しました。サイドバー、起動画面、Windows／Linux のトレイ、Windows のセットアップウィザードも新しいアイコンになります。**

- v2.12.0 ではアプリアイコンと「情報」ページを変更しましたが、サイドバー左上のマーク、起動画面、トレイは古いアイコンのままでした。
- Windows のインストール／アンインストールウィザードのようこそ画面のサイド画像と各ページのヘッダー画像は NSIS 標準の画像でしたが、新しいアイコンの画像にしました。インストーラー、アンインストーラー、macOS のディスクイメージも新しいアイコンを明示的に使います。
- アイコン生成スクリプトがこれらの同梱コピーとウィザード画像も直接書き出すようにし、今後は漏れません。

## その他

- NH Pocket は変更なし（2.12.0、アイコンは更新済み）。ファームウェアと Desktop の更新は不要です。
- macOS の Dock や Finder に古いアイコンが残る場合はシステムのアイコンキャッシュです。Dock を再起動する（またはログアウトして再ログインする）と更新されます。
