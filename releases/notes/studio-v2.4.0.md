# studio-v2.4.0

**中繼 ID 不再無故改變、同步與錄製復原更可靠，以及 v2.0.F 的新 Vref 面板（Pocket 也有）。**

## 中繼 ID

- 設定檔一時讀不到或損壞時，不會再默默換成新的中繼 ID（以前每次開啟都可能換一個，伺服器的 Relays 頁因此越來越多）。會先重試，仍失敗就把原檔備份為 `.corrupt-…` 並沿用其中的 ID。
- NH Pocket 第一次啟動只會產生一個 ID。
- 啟動到一半失敗時會收掉已建立的連線，不會留下第二條同 ID 的連線。
- 改過中繼 ID 後，仍回報舊 ID 的自家設備不會被當成別人的；剛加入的設備不會馬上被放掉。

## 同步與錄製

- 伺服器拒絕 token（例如已撤銷）時，這一輪同步會停下並提示重新登入，不再把所有錄製標成失敗。
- 上傳進度卡住時視為失敗，不再一直重送；已同步的錄製內容變了會重新上傳；計算大檔的檢查碼時不會讓 Pocket 畫面停住。
- 錄製復原會先轉換到暫存資料夾，成功後才取代原本的部分檔案；轉換失敗不會再遺失資料。
- 改主題或語言等設定不再中斷與伺服器的連線。
- Pocket 的「僅 Wi-Fi」同步會實際判斷目前的網路。

## Vref 面板（TIA-CTL v2.0.F）

- NH Studio：上方三張狀態卡（Vref 與所在區間、Rfb、飽和行數）、量程模式分段切換、Vref 滑桿（綠／黃／紅標出安全、700–800 mV、800 mV 以上），Rfb 量測、校準開關、上限與 Vref 掃描收在「工具」中；預設上限 700 mV。
- NH Pocket：設備頁新增「Vref 與量程」：Vref 與區間、Rfb、飽和行數、量程切換、量測 Rfb、Vref 回到 330 mV。
