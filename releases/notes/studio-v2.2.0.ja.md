# studio-v2.2.0

**NH Studio に TIA-CTL v2.0.F のツールを追加: Vref、校正スイッチ、Rfb 測定、レンジモード、Vref スイープ。**

## デバイス設定・ハードウェア

- Vref カード: 現在値、上限、電源投入時の値、校正スイッチの状態。Vref の設定、330 mV への復帰、上限の設定、校正スイッチの切り替えができます。約 800 mV を超えると再起動で起動に失敗することがあり、画面で警告します。
- Rfb: 「Rfb を測定」（Vref の指定も可）で各行の Rfb、ADC オフセット、状態を一覧表示します。
- レンジ: Raw、Virtual Rfb、Auto。基準 Rfb と GPIO45 リーク補償を設定できます。Rfb を測定すると Virtual と Auto がすぐ選べます。
- Vref スイープ: 一定の圧力で Vref を段階的に変え、各ステップの Rfb、Rs 中央値、レール張り付きのセル数を表示します。Rs の変動幅と CSV ダウンロード付き。返信の待ち時間はスイープの長さに応じます（最長 120 秒）。
- ID 抵抗で認識されたバッテリーは容量と充電電流を表示し、手動設定フォームを隠し、バッテリー ID を一覧に出します。

ファームウェア v1.21.0 以降が必要です（Rfb・レンジ・スイープは v1.22.0）。
