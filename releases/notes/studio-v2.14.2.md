# studio-v2.14.2

**修正 NH Pocket 切到 3D 就閃退；進入設備畫面更順；3D 改成斜角開啟。**

## NH Pocket

- 3D 閃退：發布版在縮減程式碼時刪掉了 3D 畫面元件需要的部分，一切到 3D 就關閉 app。現在 3D 可正常顯示（Pixel 4a 實測）。
- 防護：3D 若仍無法顯示，會退回 2D 並顯示提示；其他畫面發生錯誤時顯示「重試」，不會直接關閉 app。
- 進入設備畫面：板子插圖與資料路徑在進場動畫結束後才畫出，動畫不再卡頓；即時畫面的熱圖 / 3D、IMU 面板與 IO Visualizer 的腳位圖也一樣。設備畫面不再因 fps 數字變動或計時而整頁重畫。
- 3D 一開始和 Desktop 一樣從斜上方看，而不是從正上方。

## 其他

- NH Pocket 2.14.2；NH Studio 與 NH Studio headless 只改版號。Desktop 與韌體不需更新。
