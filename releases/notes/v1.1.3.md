# v1.1.3

**WebUI 的 release note 改為 Markdown 排版，並依介面語言顯示日文或英文版本。**

## 改動

- 更新區塊與「需要更新」畫面的 release note 不再是純文字，標題、清單、粗體、程式碼與連結都會正確排版。內容來自網路，只建立文字節點，不解析 HTML;連結只允許 http(s)。
- 檢查更新時，除了繁中原文 `vX.Y.Z.md`,也會一併下載旁邊的 `vX.Y.Z.ja.md` 與 `vX.Y.Z.en.md`。WebUI 依選擇的語言顯示，沒有翻譯的版本退回繁中原文；簡中介面顯示繁中原文。下載不到翻譯不算錯誤。
- 狀態 API 的 `update_state` 多了 `notes_markdown_i18n`(`{"ja": …, "en": …}`,只含存在的語言)。

## 相容性

- manifest 格式不變，仍只連繁中原文。
- 舊版 release 只有繁中原文；從這一版起每次發布都附日文與英文。
- Desktop、Hub、裝置韌體不用跟著更新。
