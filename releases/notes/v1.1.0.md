# v1.1.0

**本機 WebUI 全面改版，跟 Desktop 的 Gateway 管理視窗用同一套版面；新增「接受遠端管理」開關。**

## 新版 WebUI

- 版面比照 Desktop 的 Gateway 管理視窗：上方 4 張總覽卡（狀態、版本、服務器、轉發中的設備），左側四個分區：
  - **概覽**：Gateway ID、上游網址、通訊埠、流量、遠端管理狀態、轉發中的設備
  - **局域網設備**：轉發中 / 附近 / 已拒絕三張卡，一列一台，直接「接管」「拒絕」「允許」
  - **連線**：Gateway ID、服務器（Production / Local / Manual）、啟用、接受遠端管理
  - **軟體更新**：目前 / 最新版本、檢查更新、立即更新、更新通道、更新說明
- 網址會記住目前分區（例如 `#devices`），重新整理後停在原處；窄螢幕時側欄改為橫向標籤。
- 外觀直接用 Desktop 的配色與元件；支援深色模式，「自動」跟 Desktop 一樣依實驗室日出日落切換，頂欄按鈕可循環 自動 / 淺色 / 深色。
- A/B slot、開機階段、更新信號來源、接管請求紀錄等進階資訊收進「技術細節」，預設收合。
- 重要操作改用確認框（拒絕轉發中的設備、立即更新、重新啟動、切到 beta），取代瀏覽器內建的確認視窗。
- 操作結果用畫面下方的提示回報；設備操作失敗時會顯示原因（以前沒有任何提示）。
- 連線設定的輸入錯誤當場提示；有改動時才能儲存，並可「還原」。
- 上游未連線時，「接管」按鈕停用，並在卡片裡說明原因。
- 強制更新改為對話框，背後頁面完全鎖住。
- 補齊三種語言的翻譯（含以前漏翻的 local / manual 與硬寫的英文）。

## 接受遠端管理

- 「連線」分區新增開關「接受遠端管理」，預設開啟。
- 關閉後，Desktop 送來的所有管理指令都會被拒絕（`remote_management_disabled`），Desktop 管理視窗只剩總覽並提示到本機開啟。
- 這個開關只能在 Gateway 本機 WebUI 改，Desktop 無法自己打開。
- 必要更新仍會在閒置時自動套用（那是 Gateway 自己的機制）。

## 修正

- WebUI 的更新對話框與更新區每 2 秒閃一次：每次輪詢都把文字重設成預設句再填回。現在輪詢只改有變動的內容，設備列表也不再整塊重畫。

## 相容性

- WebUI 從 `web.py` 拆到 `newhorizons_gateway/webui/`（純檔案，不需 build）；更新包含這個資料夾。
- 搭配 Desktop v1.2.1 才會顯示「此 Gateway 未接受遠端管理」；舊版 Desktop 照常運作，只會看到指令失敗。
- 裝置韌體、Hub 都不用改。
