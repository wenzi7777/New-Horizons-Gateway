# v0.6.0

## 為 WiFi 裝置提供時間

搭配 New Horizons OS v1.12.0：WiFi 模式的裝置改為優先向 Gateway 對時，Gateway 沒有回應時才用 NTP。同一個 Gateway 底下的裝置共用一個參考時鐘，多台裝置一起收資料時對得比較齊。

- 裝置把 12 B 的對時請求（TIME_REQ，`0xE8`）送到 UDP `13250`，也就是送感測資料的同一個 port。
- Gateway 收到後立刻記下到達時間，回覆 32 B 的 TIME_RESP（`0xE9`），內含收到與送出的時間。裝置用 NTP 的四時間戳算法扣掉網路延遲。
- 封包格式與 Hub 的 ESP-NOW 對時完全相同（`newhorizons_gateway/time_service.py`）。
- 對時請求在 Gateway 本地回覆，不會轉發給後端。
- Gateway 給的是主機作業系統的時間。**請保持主機的「自動設定時間」（NTP）開啟**；Windows、macOS、Linux 預設都是開的。

## 相容性

- 舊版裝置韌體不會送對時請求，行為不變。
- 舊版 Gateway 收到對時請求會直接丟掉（它不是合法的感測封包），裝置會改用 NTP。
