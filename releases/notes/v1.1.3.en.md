# v1.1.3

**Release notes in the WebUI are now rendered as Markdown and shown in Japanese or English to match the UI language.**

## Changes

- Release notes in the update section and on the "update required" screen are no longer plain text: headings, lists, bold, code and links are laid out properly. The notes come from the network, so they are built from text nodes only, never parsed as HTML; only http(s) links are live.
- When checking for updates, the Gateway now also downloads `vX.Y.Z.ja.md` and `vX.Y.Z.en.md` beside the Traditional Chinese original `vX.Y.Z.md`. The WebUI shows the one matching the selected language and falls back to the original when a version has no translation; the Simplified Chinese UI shows the Traditional Chinese original. A missing translation is not an error.
- `update_state` in the status API gains `notes_markdown_i18n` (`{"ja": …, "en": …}`, only the languages that exist).

## Compatibility

- The manifest format is unchanged and still links only the Traditional Chinese original.
- Older releases have only the Traditional Chinese original; from this version on every release ships Japanese and English too.
- Desktop, Hub and device firmware do not need updating.
