# v0.5.6

## Arduino protocol v5

The Gateway accepts Arduino stream and heartbeat packets using protocol v5,
including the optional magnetometer and battery sections used by VD-CTL/R
v1.5.F. Existing v3 and v4 traffic remains supported.

## Reliable slot startup

If an inactive Gateway slot contains a stale or broken virtual-environment
symlink, the bootloader recreates that environment before starting the slot.
