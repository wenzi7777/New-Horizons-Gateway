# studio-v2.5.0

**NH Studio・NH Pocket・NH Studio headless が互いにデバイスを引き継げるように。引き継がれてもデバイスは一覧から消えず、サーバー WebUI の「引き受ける」も Studio で機能します。**

## デバイスの引き継ぎ

- 3 つは対等です。他で使用中のデバイスも、先に向こうで解除せずにそのまま移せます。
- NH Studio（デバイスページと設定 > デバイス）と NH Pocket：他で使用中のデバイスには「引き継ぐ」が表示され、確認のうえ実行します。設定ページとデバイスページの規則がそろいました（以前は設定ページで「Elsewhere」のデバイスにも「Add」が出ていました）。
- NH Studio headless：ローカル WebUI の「引き受ける」がサーバー未接続でも使え、デバイスが今どの中継につながっているかを表示します。
- サーバーの Relays ページの「引き受ける」が NH Studio / Pocket でも機能します（以前はデバイスが移っても応答がなく、claim がタイムアウトしていました）。

## 引き継がれたとき・自動で取り戻すとき

- 他の Studio / Pocket / headless に引き継がれたデバイスは「マイデバイス」に残り、「{中継} に引き継がれました」と表示されます。通知を一度出し、ここでの録画を止めます。「取り戻す」でいつでも戻せます。自動で奪い返すことはありません。
- 持ち主が一時的にいない間（Studio を閉じたときなど）に他の中継が受け持ったデバイスは、持ち主が戻ると自動で取り戻します。

## FindMe

- offer を第 2 版にし、受け持ち中のデバイス数を付けました。新しいファームウェアは優先度、サーバー接続、遅延、負荷の順に中継を選びます。

New Horizons OS v1.23.0 と Desktop v1.9.0 と組み合わせて使います。
