# v1.2.0

**NH Gateway の最終バージョン：今後は NH Studio に置き換わります。**

- WebUI の一番上に「NH Gateway は NH Studio に置き換わります」と表示し、ダウンロードページにリンクします。
- このバージョンはこれまでどおり動作するので、すぐに乗り換える必要はありません。新しい機能は NH Studio にのみ追加されます。
- NH Studio は同じ方法（UDP、FindMe）でデバイスを中継し、ここの設定を引き継ぎます。同じフォルダーに置くか同じコンピューターで起動すると設定を自動で引き継ぎ、Gateway ID も変わらないので、サーバーからは同じ機器に見えます。
- 画面のないコンピューターでは NH Studio headless 版（`nh-studio`）を使い、Desktop のアカウントでサインインします（`nh-studio --login`）。
