# v1.1.2

**名称を NH Gateway に統一しました。**

## 変更点

- `gateway_name` の既定値を `NHOS Gateway` から `NH Gateway` に変更しました。設定の既定値、`config.example.json`、FindMe 応答、すべてのフォールバックが対象です。
- ローカル WebUI のタイトル、コンソールのタイトル、Windows コンソールのタイトルも NH Gateway になりました。

## 互換性

- `gateway_name` は各インストールの `.run/config.json` に保存されるため、既存のインストールは元の値を保持します。Desktop v1.2.2 以降、Relays ページは常に NH Gateway と表示し、この値は使いません。
- API、プロトコル、設定形式は変わりません。Desktop、Hub、デバイスファームウェアを更新する必要はありません。
