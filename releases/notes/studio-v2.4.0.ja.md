# studio-v2.4.0

**中継 ID が勝手に変わらなくなり、同期と録画の復元がより確実になり、v2.0.F の新しい Vref パネルを追加しました（Pocket にも）。**

## 中継 ID

- 設定ファイルが一時的に読めない、または壊れているとき、新しい中継 ID に黙って切り替わらなくなりました（以前は起動のたびに変わることがあり、サーバーの Relays ページが増え続けていました）。まず再試行し、それでも失敗したら元のファイルを `.corrupt-…` として保存し、その中の ID を使い続けます。
- NH Pocket の初回起動で作られる ID は 1 つだけです。
- 起動の途中で失敗した場合は作りかけの接続を閉じ、同じ ID の接続が 2 本残らなくなりました。
- 中継 ID を変えたあとも、古い ID を報告している自分のデバイスを他人のものとみなしません。追加したばかりのデバイスをすぐ手放すこともなくなりました。

## 同期と録画

- サーバーが token を拒否した（取り消し済みなど）ときは、その回の同期を止めて再サインインを案内し、すべての録画を失敗扱いにしなくなりました。
- アップロードが進まないときは失敗とし、送り直し続けません。同期済みの録画の内容が変わったら再アップロードします。大きなファイルのチェックサム計算中も Pocket の画面が止まりません。
- 録画の復元は一時フォルダーに変換し、成功してから元の途中ファイルと置き換えます。変換に失敗してもデータを失いません。
- テーマや言語などの設定変更でサーバーとの接続が切れなくなりました。
- Pocket の「Wi-Fi のみ」同期が実際のネットワークを判定します。

## Vref パネル（TIA-CTL v2.0.F）

- NH Studio：上部に 3 つの状態カード（Vref と区分、Rfb、飽和している行）、量程モードのセグメント切り替え、Vref スライダー（安全・700–800 mV・800 mV 超を緑・黄・赤で表示）。Rfb 測定、校正スイッチ、上限、Vref スイープは「ツール」にまとめました。既定の上限は 700 mV です。
- NH Pocket：デバイス画面に「Vref と量程」を追加：Vref と区分、Rfb、飽和している行、量程の切り替え、Rfb の測定、Vref を 330 mV に戻す。
