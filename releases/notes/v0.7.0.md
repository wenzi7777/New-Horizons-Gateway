# v0.7.0

## 更新通道（正式版／測試版）

- Gateway WebUI 的 Update Center 新增「更新通道」：`stable`（正式版，預設）或 `beta`（測試版）。設定存在 `.run/config.json` 的 `update_channel`，也可以用環境變數 `NEWHORIZONS_GATEWAY_UPDATE_CHANNEL`。
- stable 讀 `releases/gateway-latest.json`，beta 讀 `releases/gateway-beta.json`；beta 也會收到每個正式版。
- Gateway 會在 `hello` 告訴後端自己的通道，後端只會把同一通道的最新版本推給它：測試版永遠不會強制推給正式版的 Gateway。
- 測試版版號 `vX.Y.Z-beta.N` 排在對應正式版之前。以前的版本比較只看數字，會把 `v0.7.0-beta.1` 當成比 `v0.7.0` 還新。
- 從 beta 切回 stable 不會降級；只屬於 beta 的「必須更新」畫面也會一起解除。

## 相容性

- 搭配 Desktop v0.22.0：後端依 Gateway 的通道回覆最新版本。舊版 Desktop 會把所有 Gateway 當成 stable，行為和以前一樣。
- 舊版 Gateway 不送通道，後端一律當成 stable。
