# v1.1.3

**WebUI のリリースノートを Markdown で表示し、UI の言語に合わせて日本語版または英語版を表示するようにしました。**

## 変更点

- 更新セクションと「更新が必要」画面のリリースノートはプレーンテキストではなくなり、見出し、リスト、太字、コード、リンクが正しくレイアウトされます。ノートはネットワークから取得するため、テキストノードのみで組み立て、HTML としては解釈しません。リンクは http(s) のみ有効です。
- 更新の確認時に、繁体字中国語の原文 `vX.Y.Z.md` に加えて、その隣の `vX.Y.Z.ja.md` と `vX.Y.Z.en.md` もダウンロードします。WebUI は選択中の言語のものを表示し、翻訳がないバージョンでは原文に戻ります。簡体字中国語の UI では繁体字中国語の原文を表示します。翻訳が見つからなくてもエラーにはなりません。
- ステータス API の `update_state` に `notes_markdown_i18n`(`{"ja": …, "en": …}`、存在する言語のみ)を追加しました。

## 互換性

- manifest の形式は変わらず、繁体字中国語の原文にのみリンクします。
- 旧リリースには繁体字中国語の原文しかありません。このバージョンから、毎回のリリースに日本語版と英語版を付けます。
- Desktop、Hub、デバイスファームウェアを更新する必要はありません。
