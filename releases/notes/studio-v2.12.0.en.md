# studio-v2.12.0

**NH Studio and NH Pocket have new icons that are easy to tell apart, and the setup wizard now calls the default server "Production server".**

## New icons

- Inspired by the New Horizons flyby of Pluto, keeping the horizon of the old icon and adding detail.
- NH Studio: a dark sky, a gently curved horizon, a planet with phase shading and a soft halo, and Charon in the upper left.
- NH Pocket: a green sky with a large crescent planet cropped in the lower-right corner and a phased Charon in the upper left: a different viewpoint, clearly distinct from Studio.
- Updated everywhere: the macOS, Windows and Linux app icons, the Android adaptive icon (including the monochrome themed icon) and the animation on the About page.

## Setup wizard

- The server option "University" is now "Production server (default)" ("Production" in Pocket). The address is unchanged.

## Other

- NH Pocket 2.12.0. Firmware and Desktop need no update.
