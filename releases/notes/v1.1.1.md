# v1.1.1

**本機 WebUI 的控件改成跟 Desktop 一致；頂欄不再重複顯示連線狀態。**

## 改動

- **頂欄拿掉「在線」標籤。** 總覽的狀態卡已經顯示同樣的資訊。Gateway 本機服務沒有回應（重新啟動中或已停止）時，改由狀態卡顯示「無法連線」。
- **主題按鈕改用 Desktop 的圖示**（lucide 的 SunMoon / Sun / Moon，17 px），提示文字的寫法也跟 Desktop 一樣，例如「外觀：自動 · 17:02 切換為深色」。
- **下拉選單改用 Desktop 的樣式**：語言和更新通道都改成按鈕＋浮出選單，已選項目前面有勾，可以用方向鍵、Home/End、Enter/空白鍵、Esc 操作，也支援打字跳到對應選項。
- **勾選框跟 Desktop 一樣**：使用原生勾選框配上主色，不再自訂尺寸。
- 按鈕的鍵盤焦點框、ghost 按鈕的顏色和 hover 效果也對齊 Desktop。

## 相容性

- 只改 WebUI（新增 `webui/select.js`），API 和設定都不變。
- Desktop、Hub、裝置韌體都不用更新。
