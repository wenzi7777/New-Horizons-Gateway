# studio-v2.1.0

**首次開啟引導、Desktop 的裝置設定與可視化、全部自製元件、轉送效能測試；標籤與描述檔以伺服器為準；headless 改為和 Hub 同一個地位。**

## 首次開啟

- NH Studio 與 NH Pocket 第一次開啟時會引導：選伺服器 → 用 Desktop 帳號登入（可略過）→ 是否自動上傳錄製 → 裝置接受方式。
- 裝置接受方式預設為「只接受我加入的裝置」；「接受所有請求的裝置」就是舊 NH Gateway 的運作方式。設定裡可以再次開啟引導。

## NH Studio

- 裝置設定照搬 Desktop：總覽、硬體、串流、更新、診斷五個分區，卡片與指令和 Desktop 相同。
- 即時畫面照搬 Desktop 的可視化：3D 曲面 / 2D 熱圖、描述檔選擇、鏡像、統計與壓力中心。
- 所有下拉選單、輸入框、勾選框、開關都改成自製元件，不再使用系統原生元件；圖示按鈕統一放大。
- Windows / Linux 拿掉系統標題列與選單列，改成自製的最小化 / 最大化 / 關閉按鈕。macOS 不變。
- macOS 改為 ad-hoc 簽章：Apple Silicon 不再顯示「已損壞」，第一次開啟請在「系統設定 → 隱私權與安全性」按「強制打開」。
- 頂端列新增「打開 Desktop」按鈕。
- 簡體中文的 Profiles 改為「描述文件」。

## NH Pocket

- 開關、下拉選單（底部彈出）與輸入框改成自製元件；2D 熱圖依 Desktop 的排版、P 編號與圖例重畫，點一格會顯示數值。
- 設定頁新增「打開 Desktop」。

## 標籤與描述檔以伺服器為準

- 裝置暱稱、群組與描述檔不再雙向同步，改為直接編輯伺服器上的資料，本機只保留唯讀副本。
- 離線或未登入時無法編輯，畫面會顯示「需要連上伺服器」。

## 轉送效能測試

- Studio「工具 → 轉送效能」、Pocket「設定 → 轉送效能」、headless `nh-studio --bench`：量測這台機器每秒能處理的幀數、到伺服器的來回時間與上傳速度，估算能轉送幾台裝置並指出瓶頸。

## NH Studio headless

- 改為和 Hub 同一個地位：連線種類 `relay`、不需要登入、只轉送不錄製；移除 `--login` 與 WebUI 的登入卡片。

## 其他

- 發布檔案經 VirusTotal 掃描，下載頁顯示掃描結果。
- 需要 New Horizons Desktop v1.5.0 以上；建議搭配韌體 v1.20.0（裝置不再在主機之間來回跳）。
