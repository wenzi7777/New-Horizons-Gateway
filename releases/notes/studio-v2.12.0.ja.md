# studio-v2.12.0

**NH Studio と NH Pocket のアイコンを新しくし、ひと目で区別できるようにしました。セットアップウィザードの既定サーバーは「本番サーバー」と表示します。**

## 新しいアイコン

- New Horizons 探査機の冥王星フライバイをモチーフに、これまでの地平線の構図を残して細部を加えました。
- NH Studio：暗い夜空、ゆるやかに曲がった地平線、満ち欠けの陰影と光のにじみをもつ惑星、左上にカロン。
- NH Pocket：緑の空に、右下で画面に切り取られた大きな三日月形の惑星と、満ち欠けのあるカロン。視点を変え、Studio とはっきり区別できます。
- macOS・Windows・Linux のアプリアイコン、Android のアダプティブアイコン（モノクロのテーマアイコンを含む）、「情報」ページのアニメーションを更新しました。

## セットアップウィザード

- サーバーの選択肢「大学」を「本番サーバー（既定）」（Pocket では「本番」）に変更しました。接続先は変わりません。

## その他

- NH Pocket 2.12.0。ファームウェアと Desktop の更新は不要です。
