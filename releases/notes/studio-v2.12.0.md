# studio-v2.12.0

**NH Studio 與 NH Pocket 換上新圖示，兩者一眼就能分辨；設定精靈裡的預設伺服器改稱「正式伺服器」。**

## 新圖示

- 以 New Horizons 探測器飛越冥王星為靈感，沿用原本的地平線構圖並加上細節。
- NH Studio：深色夜空、微彎的地平線，帶月相陰影與光暈的星球，左上方是 Charon。
- NH Pocket：綠色天空中，右下角一顆被畫面截掉的大彎月星球，左上方是帶月相的 Charon，換了視角，和 Studio 明顯不同。
- macOS、Windows、Linux 的應用程式圖示，Android 的自適應圖示（含單色主題圖示），以及「關於」頁的動畫都已更新。

## 設定精靈

- 伺服器選項「大學」改為「正式伺服器（預設）」（Pocket 為「正式」），連線位址不變。

## 其他

- NH Pocket 2.12.0。韌體與 Desktop 不需更新。
