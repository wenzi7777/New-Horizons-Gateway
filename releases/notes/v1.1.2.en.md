# v1.1.2

**The name is now NH Gateway everywhere.**

## Changes

- The default `gateway_name` changes from `NHOS Gateway` to `NH Gateway`, including the settings default, `config.example.json`, FindMe replies and every fallback.
- The local WebUI title, the console title and the Windows console title also read NH Gateway.

## Compatibility

- `gateway_name` is stored in each installation's `.run/config.json`, so existing installs keep their current value. From Desktop v1.2.2 the Relays page always shows NH Gateway and no longer uses this value.
- API, protocol and config format are unchanged; Desktop, Hub and device firmware do not need updating.
