# v1.2.0

**The last NH Gateway release: NH Studio replaces it from now on.**

- The web UI shows "NH Gateway is replaced by NH Studio" at the top, with a link to the download page.
- This version keeps working as before, so there is no need to switch at once; new features come only in NH Studio.
- NH Studio relays devices the same way (UDP, FindMe) and takes these settings over: placed in the same folder or started on the same computer it picks them up, the Gateway ID stays, and the server sees the same relay.
- On computers without a screen use NH Studio headless (`nh-studio`) and sign in with a Desktop account (`nh-studio --login`).
