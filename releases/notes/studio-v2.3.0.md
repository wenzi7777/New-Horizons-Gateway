# studio-v2.3.0

**NH Pocket 加入錄製分析，NH Studio 開啟 CSV 時會一併帶入事件與 meta。**

## NH Pocket

- 每筆錄製新增**分析**畫面（打開錄製，按「分析」）：總覽；總和／峰值／接觸面積／指定感測器的曲線，可以拖曳游標，也能用 0.5×、1×、2×、4× 播放；游標所在幀的熱圖（或可見範圍的平均／峰值）；取樣品質，並列出遺失幀、間隙與重啟，點一下就跳到該處；各感測器統計與錄製的事件。
- Pocket 以分塊讀取 CSV，長時間的錄製不會讓畫面凍結。分析的是手機上錄下的資料。

## NH Studio

- 工具 > 資料分析：從磁碟開啟 CSV（例如 Desktop 匯出的檔案）時，會同時載入旁邊的 `.events.csv` 與 `.meta.json`，所以事件、設備資訊與熱圖的欄數都會出現。
- 「錄製」頁新增**分析**按鈕，直接在分析工具中開啟選取的錄製。
