# studio-v2.13.0

**NH Studio と NH Pocket が「イラスト」表示に：デバイスはボードの図になり、ライブ値が実際の部品から引き出し線で示されます。デバイスがつながると、更新を押さなくても設定がすぐ表示されます。**

## イラスト表示（v2.0.F / v1.5.F / v1.0.F）

- 設定 → 一般に「インターフェース」（イラスト／クラシック）を追加。既定はイラストで、クラシックに戻せます。GCU LTS ボードには図がなく、従来のカードのままです。
- デバイスの概要：ボードのベクター図（PCB ファイルの実際の位置、ライト／ダークテーマに追従）と、両側のクリックできる値（バッテリー、読み取りモード、スキャン FPS とマトリクス、接続、ファームウェア、ライト）。クリックで該当する設定へ移動します。スキャンとピンは「マトリクス」1 つにまとめ、引き出し線が 2 つの FPC に分岐します。
- 電源と接続の経路：USB-C／バッテリー → 充電 → システム、デバイス → 中継 → サーバー。使用中の経路を実線で表示します。長い文字は中央を省略し、切れなくなりました。
- IO Visualizer：2 つの FPC の拡大図。ピンごとに四角で示し、有効なピンが点灯します。
- 読み取りモード、スキャンのプリセット、ストリームバッファ、更新チャネル、テーマなどは大きな選択ボタン（選択中はチェック）に。送信はこれまでどおり「適用」を押したときです。
- 充電中のバッテリーアイコンは、稲妻を電池の中に描き、くり抜きの縁取りで目立つようにしました。

## NH Studio

- デバイスがつながった（つながり直した）ときに自動でステータスを 1 回取得し、設定パネルが空のままになりません。応答がなければ 15 秒ごとに最大 5 回まで再試行します。NH Pocket も同様です。
- デバイス設定を Desktop と同じ分け方に：接続、ハードウェア、ストリーミング、時計、アップデート、メンテナンス、アプリ、診断、ファイル、実験的。「概要」は「接続」に改名。再起動は「メンテナンス」、フィルターと Raw ADC は「実験的」、ログは「ファイル」へ移動しました。
- 「診断」にデバイスの健康状態カード（通電時間、起動回数とクラッシュ回数、リセット理由、OTA ロールバック、チップ温度、最小空きメモリ、Wi‑Fi 切断回数）を追加。Desktop と同じです。
- ツール → デバイスファイルを Desktop の Finder 風ウィンドウに：左に範囲（ファイル数付き）、ファイル一覧、閉じられるプレビュー、下部にストレージ表示。
- 「Generate code」と IO ウィンドウの「コピー」が必ず失敗していた問題を修正：Studio 自身のページはクリップボードに書き込めるようになりました（ほかの権限はすべて拒否のまま）。

## その他

- v1.5.F / v2.0.F のデジタル FPC のピン表示を修正：接点 18 = GND、17 = SCL（GPIO 42）、16 = SDA（GPIO 40）、15 = NC。
- IO Visualizer のボード図を小さく（Studio 460 px、Pocket 280 pt）。v2.0.F 裏面の Rfb0–13 の位置と、どれがはんだ付けされているかを表示します。
- NH Pocket 2.13.0。NH Studio headless はバージョン番号のみ変更。Desktop v1.16.0 と組み合わせて使用。ファームウェアの更新は不要です。
