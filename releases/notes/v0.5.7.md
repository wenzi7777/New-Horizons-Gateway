# v0.5.7

## NHOS 品牌縮寫

顯示用的短標籤統一縮寫為 NHOS,與韌體 v1.0.0、Desktop v0.7.0 一致。

- 預設 `gateway_name`:`New Horizons Gateway` → `NHOS Gateway`,涵蓋設定預設值、
  FindMe 回應與所有 fallback
- WebUI 標題列與 en/ja/zh 三語的 `appTitle`
- 主控台標題列與 Windows console 標題
- Gateway 自行合成的 `device_name`:`New Horizons OS-<UID>` → `NHOS-<UID>`,與
  韌體現在回報的字串逐字一致

啟動 log 與 argparse 說明維持長名稱不變。

## 升級注意

`gateway_name` 是**每個安裝各自持久化**在 `.run/config.json` 裡的,所以既有安裝
升級後仍會沿用原本的名稱,只有全新安裝才會拿到新的預設值。該欄位本來就可由使用者
編輯,要改成新名稱直接在 WebUI 改即可。
